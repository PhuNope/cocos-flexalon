# Flexalon Cocos v0.5.12 — Release Notes

**Ngày:** 26/11/2026
**Cocos Creator:** >=3.8.2
**Nâng cấp:** v0.5.11 → v0.5.12
**Gizmos tùy chọn:** Cocos-Gizmos v3.0.3+

## Sửa build và Git submodule

- Sửa lỗi TS2451 khi `@types/node` tồn tại trong node_modules của project Cocos cha.
- Guide Panel có module scope riêng, giữ CommonJS export. TypeScript 5.8.3 không tự nạp ambient @types; không emit JS khi build lỗi.
- npm postinstall tự sinh `dist/` khi cài dependency dev từ source. Không track `dist/` trong Git.
- ZIP release vẫn build sẵn và sử dụng được mà không cần npm.
- CI Windows và Linux của bản dev 8531552 đã pass; không thay đổi thuật toán layout, UUID hoặc tích hợp Gizmos v3.

## Cài từ Git submodule

Tại project Cocos cha (Node.js >=18):

```bash
git submodule update --init --recursive -- extensions/flexalon-tools
npm --prefix extensions/flexalon-tools ci --include=dev
```

Git khôi phục commit mà project cha đã pin. Lệnh npm tự chạy build. Để tự động hóa cùng npm install của project cha, thêm setup:flexalon và gọi nó từ postinstall hiện có theo README_VI. Git clone hay submodule update đơn thuần không tự chạy npm.

## Cài từ ZIP

Tải `flexalon-tools-v0.5.12.zip` từ GitHub Releases hoặc dùng Check Update. ZIP đã có dist và không cần build thêm.
