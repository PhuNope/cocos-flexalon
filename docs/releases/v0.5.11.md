# Flexalon Cocos v0.5.11 — Release Notes

**Ngày:** 26/11/2026
**Cocos Creator:** >=3.8.2
**Nâng cấp:** v0.5.10 → v0.5.11
**Gizmos tùy chọn:** Cocos-Gizmos v3.0.3 hoặc bản dev v3 mới hơn.

## Tương thích Cocos-Gizmos v3

- Adapter dùng global `Gizmos2D` của extension cài riêng, không bundle hoặc import SDK lần hai.
- Đồng bộ world-space trước khi vẽ; giữ anchor Canvas ẩn và không lưu để tránh dùng nhầm renderer khi chọn layout lồng nhau.
- Dọn anchor khi selection thay đổi; cho phép SDK flush renderer đang idle, kể cả trong Scene tab khôi phục.
- Grid Cell Index dùng API drawLabel v3 với giới hạn 11–22 pixel màn hình.
- Chỉ gọi SDK trong Scene Editor, không chạy ở Preview/game; thiếu extension vẫn sử dụng layout bình thường.
- Giữ nguyên thuật toán layout, dữ liệu serialized và UUID asset.

## Kiểm thử

- Regression test mới cho SDK tùy chọn, tọa độ world-space, selection, idle frame, label và Preview/game.
- Dev QA commit d9ee454 đã thành công; người dùng xác nhận kiểm thử bản dev đạt yêu cầu.

## Nâng cấp

Cập nhật qua Check Update hoặc tải ZIP chính thức `flexalon-tools-v0.5.11.zip` từ GitHub Releases. Nếu sử dụng Gizmos, cập nhật riêng [Cocos-Gizmos](https://github.com/PhuNope/Cocos-Gizmos/releases) lên v3.0.3 hoặc bản v3 mới hơn. Không cần copy runtime Gizmos vào Flexalon.
