# Flexalon Cocos v0.5.10 — Release Notes

**Phát hành:** 09/11/2026
**Cocos Creator:** >=3.8.2
**Nâng cấp:** v0.5.9 → v0.5.10

## 1. Scale To Fit cho mọi Layout

- Tất cả 7 Layout (Grid, Flexible, Align, Circle, Curve, Shape, Random) có `Fit Children`, `Fit Padding` và `Fit Item Size`.
- Từng `FlexalonObject` có `Fit Mode` (Inherit/None/ScaleToFit), `Fit Source Size`, kiểm soát Min/Max theo Visual Size và scale giữ tỷ lệ.
- Grid chỉ còn `Cell Padding` riêng; công tắc Grid Fit cũ tự di chuyển qua Fit Children chung.
- Flexible Fit dùng phần không gian còn lại; hỗ trợ parent Width/Height = Layout đo Visual Size sau Fit, không lặp cache size.

## 2. Fix quan trọng: chuyển Flexible → Grid

- Không còn scale bị kẹt (ví dụ `2.9375`) sau khi đổi/disable layout; scale baseline được sở hữu bởi layout đang hoạt động và giải phóng đúng lifecycle.
- Khôi phục kích thước nguồn trước khi Grid mới đo item, bảo toàn sửa đổi thủ công trong Editor và không yêu cầu xóa component.
- Với `Fill`, UITransform vẫn tuân theo bố cục. Muốn chỉnh Content Size trực tiếp, hãy chuyển qua `Component` hoặc bật `Preserve UI Content Size`.

## 3. Hướng dẫn / kiểm thử

- Guide tiếng Việt có 20 bài, gồm một bài riêng minh họa Scale To Fit từng bước, Min/Max, padding, Grid và Flexible.
- Thêm behavioral tests cho chuyển layout, thay đổi Node Scale, disable/re-enable và các trường hợp Size Type.
- Đã test bản dev thành công; release workflow tự build và kiểm tra CRC ZIP.

## Nâng cấp

1. Lưu Scene/Prefab, sao lưu project.
2. Cập nhật qua Check Update hoặc tải `flexalon-tools-v0.5.10.zip`, chép vào `<project>/extensions/flexalon-tools/`.
3. Mở lại Cocos Creator. Với Scene/Prefab từ dev cũ bật Fit Children To Cell, lưu lại để ghi Fit Children mới.
